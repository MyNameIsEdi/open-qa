
# 🧠 Smart Test Data Generator (LLM)

Static test data and standard libraries (like Faker.js) are great for the "happy path", but they often fail to generate the truly chaotic, unexpected edge cases that break production systems. 

This module leverages the **Anthropic Claude API** to dynamically generate extreme edge-case payloads (JSON) for E-commerce API and UI testing.

---

## 🏗️ Architecture & Prompt Engineering

To maintain a scalable and clean codebase, this module uses **Decoupled Prompt Engineering**:
* **Execution Logic (`generate-test-data.ts`):** Handles the API connection, error handling, and file system I/O.
* **Prompt Management (`/prompts`):** System personas and user tasks are isolated into modular functions. This makes it easy to add new data scenarios (e.g., Banking, Healthcare) without touching the core API logic.

### Directory Structure
```text
02-Smart-Data-Gen/
├── prompts/
│   └── ecommerce-edge-cases.ts  # Isolated prompt templates and personas
├── generate-test-data.ts        # Main execution script
└── generated-edge-cases.json    # The output file generated by the LLM

```

---

## 🔥 Generated Scenarios

The LLM is instructed to act as a "Hacker QA" and generates JSON data containing:

1. **Extreme boundary limits** (massive quantities, negative prices).
2. **Encoding issues** (Emojis, RTL languages, special characters in names).
3. **Security Vectors** (Basic SQLi and XSS payloads in address fields).

## 💻 How to Run

### 1. Prerequisites

Ensure you have installed the required dependencies from the root project and have an Anthropic API key.
Create a `.env` file in the **root** directory of this repository:

```text
ANTHROPIC_API_KEY=sk-ant-api03-...

```

### 2. Execute the Generator

Run the TypeScript file directly using `tsx`:

```bash
npx tsx generate-test-data.ts

```

### 3. Consume the Data

Once executed, a fresh `generated-edge-cases.json` file will be created. You can easily import this JSON file into Playwright Data-Driven Tests or Postman collections to fuzz your system.
