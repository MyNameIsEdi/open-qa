Quick Start (< 5 minutes)

All demos run in MOCK mode by default — no ANTHROPIC_API_KEY required. Perfect for evaluating the toolkit locally before wiring up a live LLM.

1. Clone & Install

terminal bash 
git clone https://github.com/MyNameIsEdi/intelligent-testing-toolkit.git
cd intelligent-testing-toolkit
npm install
npx playwright install chromium

2. Run Your First Demo

terminal bash 
npm test                    # Playwright specs (self-healing + helpers)
npm run verify:demos        # Run all three demo scripts + verify outputs
npm run typecheck           # Strict TypeScript check
lightbulb All three demo scripts write artifacts to output/. Check output/generated-edge-cases.json and output/AI_BUG_REPORT.md after running npm run verify:demos.

Mock vs Real LLM Mode

The toolkit ships with a dual-mode LLM client in src/core/. When ANTHROPIC_API_KEY is absent (or MOCK_LLM=true), every agent and skill returns a deterministic hard-coded response so your CI pipeline never needs credentials.

MOCK mode (default) Real LLM mode
API key requiredNoYes
ResponseDeterministic fixtureLive Claude 3.5 Sonnet
Latency<10ms~800ms – 2s
Cost$0~$0.01 – $0.02 per call
CI safeYesRequires secrets

Switching to Real LLM

terminal bash 
cp .env.example .env
# Edit .env and set:  ANTHROPIC_API_KEY=sk-ant-...
npm run run:healing
npm run run:datagen
npm run run:bugreport
lightbulb Keep ANTHROPIC_API_KEY out of source control. The project's .gitignore already excludes .env. Use GitHub repository secrets for CI runs that need live LLM calls.

Autonomous Agents

Agents are higher-order orchestrators in src/agents/. They combine multiple skills and LLM calls to autonomously reason about and recover from test failures.

Self-Healing Locator

When a Playwright test fails because the UI changed, the Self-Healing agent submits the stripped DOM context to Claude and receives a replacement getByRole / getByTestId locator suggestion — with no manual intervention.

terminal bash 
npx tsx src/agents/self-healing.ts
# or via the Playwright test suite:
npm run test:healing

Add to Claude / MCP

Any agent or skill card on the marketplace has an Add to Claude button. Clicking it copies the tool's system prompt to your clipboard, ready to paste into a Claude conversation or project.

Using with Claude Projects

  1. Open Agents, Skills, or Prompts.
  2. Click Add to Claude on any card.
  3. In Claude.ai, create or open a Project and paste the prompt into the Project Instructions field.
  4. Claude will now act as the specified QA persona for all conversations in that project.

MCP Integration (Advanced)

The agents in src/agents/ can be exposed as MCP tools by wrapping them in a Model Context Protocol server. This lets Claude call the Self-Healing or Data Gen logic as a native tool during agentic tasks.

terminal bash 
# Example: add toolkit as local MCP server in Claude Desktop
# claude_desktop_config.json
{
  "mcpServers": {
    "itk": {
      "command": "npx",
      "args": ["tsx", "src/core/mcp-server.ts"],
      "cwd": "/path/to/intelligent-testing-toolkit"
    }
  }
}
lightbulb MCP server support is on the roadmap. Watch the GitHub repo for the src/core/mcp-server.ts release.

FAQ

Do I need an Anthropic API key?
No. All demos work in MOCK mode. Set ANTHROPIC_API_KEY in .env for live Claude calls.
Can I use Cypress or Selenium instead of Playwright?
The AI patterns (LLM client, prompt templates, output parsing) port cleanly to any framework. This repo is optimised for Playwright Test and its built-in assertion model.
How do I integrate with CI?
See .github/workflows/playwright-ci.yml — it runs npm test on push/PR to main with Chromium and uploads a test report as an artifact. No API key is needed because MOCK mode is the default.
Can I contribute a new agent or skill?
Yes — contributions are welcome. Fork the repo, add your skill under src/skills/ or src/agents/, write a matching Playwright test, and open a PR. See the Contributing section in the README for the full checklist.
What models are supported?
The LLM client in src/core/ targets Claude 3.5 Sonnet by default. You can swap the model string to any Anthropic model (e.g., claude-opus-4-7) by editing src/core/llm-client.ts.
Is the God-Mode .cursorrules prompt safe to commit?
Yes — it contains no secrets, only instructions. Commit it as .cursorrules at the root of your project and Cursor will automatically apply it to every conversation in that workspace.
